# Project 10 — Restaurant Orders & Menu Performance Analyzer

## 1. Project Overview

This project was developed for the **Programming Techniques** course as a Python application designed to analyze restaurant orders and menu performance.

The application combines two CSV datasets containing menu information and customer order records. By matching orders to menu items, it provides insights into sales volume, revenue, estimated costs, gross margins, and menu-item profitability.

The main objective is to help restaurant management understand product performance, identify demand patterns, evaluate hypothetical pricing scenarios, and generate recommendations for menu optimization.

In addition to the core analysis, the application includes synthetic order generation, detailed temporal analysis, graphical dashboards, hypothetical price simulations, and rule-based menu recommendations.

The main analytical calculations rely on fundamental Python programming concepts, including functions, loops, conditions, dictionaries, lists, and sorting. Pandas and Matplotlib are used to complement these calculations through data organization and visualization.

### 4.1. Application Execution Flow

The application follows a structured sequence of operations coordinated by `main.py`.

1. **Data loading and validation:** The application reads the original menu and order files or generates synthetic orders when requested. Input records are validated, and invalid records are identified and reported.

2. **Order matching and financial calculations:** Valid orders are matched to menu items using `item_id`. The application calculates quantities sold, revenue, estimated costs, and gross margins at the item and category levels.

3. **Performance and temporal analysis:** Menu items are ranked according to sales volume and gross margin. Demand is also analyzed by time of day, weekday, and combined weekday/time-period intervals.

4. **Price simulation and recommendations:** The application generates rule-based recommendations for menu items and evaluates hypothetical price changes. A specific price-change scenario is calculated when requested through the command-line interface.

5. **Report generation and visualization:** The calculated results are organized into CSV files, a structured textual report, a graphical performance dashboard, and a price-sensitivity chart.

6. **Output storage:** The application saves the generated results in the `results/` directory, allowing users to inspect and compare restaurant performance indicators.

### 4.2. Design Principles

The project was developed using a modular structure to ensure that individual components can be understood, maintained, and tested independently.

The main analytical calculations are implemented primarily using fundamental Python constructs, including functions, loops, conditional statements, lists, dictionaries, and sorting operations.

External libraries such as Pandas and Matplotlib complement these calculations by supporting data preparation and graphical visualization rather than replacing the core analytical logic.

This separation of responsibilities also allows the application to reuse the same analytical functions when processing both the original course data and synthetically generated orders.
