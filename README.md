# Project 10 — Restaurant Orders & Menu Performance Analyzer

Read `Project_Specification.pdf` first. The Section 2 checklist must be completed and agreed with the instructor before implementation.

`data/` contains the reference input files and their DATA_README. Do not modify these reference files; use additional copies for testing.

Run the application in the way documented by your group in the submission README.

## What your group must include in the final submission README

List the group members, agreed requirements and total PCP, dependencies, and exact run commands. Also add an **implementation evidence summary** (in your final README or a separate linked file): one entry for **every selected requirement**, including C01–C04, M requirements, and selected S/E tasks. For each entry give the requirement ID, relevant `.py` file(s) and function(s), and a short explanation of how the code implements it. A table with columns `Requirement | Where in code | How it is implemented` is sufficient. Do not claim implementation of unselected tasks.

Optional technologies such as a GUI, database or machine learning are permitted, but they do not automatically earn additional PCP unless agreed in advance. The required command-line entry point must remain available.
